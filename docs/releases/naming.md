# Provisional project name

The 2026-11-12 screening found a material collision with an existing open-source Linux cooling dashboard named [ThermalDeck](https://github.com/JR-Yu6197/thermaldeck). GitHub also contains an unrelated [ThermalDeck Nastran utility](https://github.com/StressAutomationTools/ThermalDeck). The name appears in [Stiebel Eltron HVAC product literature](https://www.stiebel-eltron-usa.com/sites/default/files/pdf/2015%20Price%20List_1.pdf) and construction marks. An indexed EU record identifies a refused THERMALDECK application (015833437) and a registered THERMALDECK POLIURETANOS mark (015949134). Check official registers for any release market.

Registry RDAP returned a registration for [thermaldeck.com](https://rdap.verisign.com/com/v1/domain/thermaldeck.com). The [.app registry lookup](https://pubapi.registry.google/rdap/domain/thermaldeck.app) returned 404. Registry results and the public GitHub search are point-in-time observations and do not reserve names.

Keep the working name for local development. Candidate alternatives for a separate search include VentGauge, ZoneRPM, and Thermal Slate. The owner should select and clear a public name and distribution bundle identifier before publishing. No trademark clearance is claimed.
