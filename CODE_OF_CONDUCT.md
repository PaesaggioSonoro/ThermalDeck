# Code of conduct

ThermalDeck adopts the [Contributor Covenant Code of Conduct, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) for project spaces. The standard is maintained by the Contributor Covenant project and licensed under [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/).

Report conduct concerns privately to the project owner through an existing contact channel. A public reporting contact has yet to be configured. The owner should treat reporters' identities and details confidentially, limit disclosure to what an investigation requires, and use the Covenant's enforcement guidance.
